What can Syllune check?

Exact arithmetic, expressions in x through degree 8, linear and quadratic real equations, and polynomial derivatives using d/dx(...). Use “or” between alternative solutions.

Variable denominators, inequalities, functions such as sin, multiple variables and more complex equations stay unverified. A check compares lines; it does not establish that your starting problem is correct.

A few things that help.

  1. Write or import. Use a stylus, touch or mouse. Select ink with a rectangle and drag it to move.
  2. Review the transcript. Type the math, or use Read ink in the Mac companion. Recognition may confuse symbols.
  3. Check the chain. Green means the transition holds in the supported language. Amber means it needs your review.
  4. Build understanding. Practice the flagged topic, use hints, and return when it’s due.
